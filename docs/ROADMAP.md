# Research roadmap

## Phase 0 — auditable prototype
- [x] Evidence history with source/time metadata
- [x] Contradiction tracking
- [x] Delayed source-reliability feedback
- [x] Recency-weighted prediction
- [x] Synthetic prequential benchmark and tests

## Phase 1 — fair comparisons
- [x] Add label-feedback frequency control
- [ ] Add replay-based baseline and controlled ablations
- [ ] Separate supervision advantage from algorithmic advantage
- [ ] Add confidence intervals and calibration metrics

## Phase 2 — external validity
- [ ] Select a public continual-learning benchmark and freeze a protocol
- [ ] Compare against published methods with matched compute budgets
- [ ] Track memory footprint, update cost and inference latency

## Phase 3 — discovery capabilities
- [ ] Question/hypothesis generation with provenance
- [ ] Experiment planner with bounded budgets
- [ ] Independent verifier and evidence ledger
- [ ] Graph-backed cross-domain memory
- [ ] Adaptive learning-policy selection

A roadmap item is not an implemented feature. Each item must become a separately tested milestone.
